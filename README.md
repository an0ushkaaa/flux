# Flux

Flux is an autonomous crypto-trading agent that combines large language model reasoning with real-time market data to identify, evaluate, and execute trading opportunities on EVM-compatible chains. It ingests live price feeds from CoinGecko, on-chain activity from Etherscan, and sentiment signals from CryptoPanic, then uses Claude (Anthropic) for high-level decision-making and Gemini embeddings stored in a pgvector-backed PostgreSQL database for long-term memory and skill retrieval. A suite of pluggable trading skills — ranging from aggressive momentum strategies to conservative dip-buy approaches — guides the agent's behaviour, while a FastAPI dashboard provides real-time visibility into positions, decisions, and performance metrics. Scheduled tasks run via APScheduler to continuously scan markets, consolidate memories, and manage open trades, all operating against Ethereum's Sepolia testnet for safe, low-risk experimentation before any mainnet deployment.
